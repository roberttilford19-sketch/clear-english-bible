This index is the one place where the whole Clear English Bible package is counted, book by book, against the files actually on disk. It exists so that completeness is provable rather than assumed: every book in the canon is listed, every book carries a status, and every status that claims work done points to the evidence file that carries it. It is a working index for the desk. It is not a publication, and nothing in it is published, emailed, posted, or uploaded.

The lane's ladder is NOT STARTED → DRAFTED → AUDITED. Work stops at AUDITED, pending Robert Tilford's read-through. No book is ever marked finished or definitive in this index. The base text throughout is the World English Bible Classic (WEB Classic, public domain), with the King James Version and the American Standard Version (1901) as controls only, and no copyrighted modern translation used as a base or skeleton. The divine name is rendered "Yahweh" throughout, by Robert's ruling of 2026-10-12 (PROJECT-PARAMETERS.md, Parameter 1). The canon is the 73-book Catholic canon, by Robert's ruling of 2026-10-13 (PROJECT-PARAMETERS.md, Parameter 2), built as the superset from which a 66-book Protestant edition can later be extracted.

Chapter counts in the master table are the standard chapter divisions for each book. Verse counts are given only where they have been verified from the files on disk, or where a source named in the row states them. Every other verse count is left blank rather than filled from memory.
